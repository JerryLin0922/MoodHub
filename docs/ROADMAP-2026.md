# MoodHub 产品路线图 2026

> 更新日期：2026-09-28（第二轮：监管对齐细化）
> 基于第一性原理：MoodHub 的本质价值 = **私密的自我记录 + 即时的情绪陪伴 + 可回溯的数据洞察**。所有功能决策以不破坏「本地优先」为底线。

## 第一性原理审视

- 用户真正需要什么？被听见（树洞）、被理解（AI 回复）、看见自己的变化（总览 / 量表）。
- 行业证明什么？「不需要被教育，只需要被听见」；隐私是 2026 年最强差异化；监管正把「无治疗主张 + 本地处理」变成最低摩擦路径。
- 我们坚决不做什么？不做云端账号、不做广告 SDK、不做情感成瘾设计、不把用户数据用于任何训练、不做任何治疗性宣称。

## 阶段一：隐私地基加固（当前 ~ v0.2）

- [ ] 危机资源全球化：内置中国大陆（12356）、香港（18111 / Open噏）、美国 / 加拿大（988）等多地区资源卡
- [ ] 数据导出：一键导出全部日记 / 树洞 / 量表记录（JSON + CSV）
- [ ] 数据清除：一键清空全部本地数据（含 AI Key 持久化项）
- [ ] 离线可用性验证：飞行模式下全功能回归测试

## 阶段二：洞察闭环（v0.3）

- [ ] 情绪可视化：树洞 / 日记自动提取情绪关键词，生成「情绪足迹」时间线（借鉴能量卡片思路，纯本地规则引擎）
- [ ] 周期性回顾报告：周报 / 月报（睡眠、心情、量表趋势）
- [ ] 情绪模式提示：如「最近 7 天焦虑评分上升」的本地规则提示 + 建议资源卡

## 阶段三：AI 深化与合规（v0.4+）

- [ ] 本地 LLM 接入（Ollama / LM Studio 协议）：真正全离线的 AI 回复
- [ ] 未成年人模式：响应《人工智能拟人化互动服务管理暂行办法》与未成年人网络保护指南、加州 SB 243、EU AI Act 年龄保证要求，为 <18 用户提供纯本地记录模式，与陪伴式 AI 交互隔离；不提供虚拟亲密关系类交互；年龄判定须超越自选复选框（参考"reasonable verification"标准）
- [ ] AI 身份标识：所有 AI 回复明确标注「AI 生成」并周期性提醒（对齐加州 SB 243 / EU AI Act /《办法》思路）
- [ ] 防依赖设计：AI 回复不做过度迎合、不诱导持续停留，设置会话边界与休息提示；连续使用超 2 小时弹窗休息提醒（对齐中国《办法》）
- [ ] 可选 E2EE 备份（实验性）

## 阶段四：合规与信任增强（v0.5+，2026-09 新增）

- [ ] 合规文案基线：商店页 / 应用内免责声明明确「非治疗、非危机服务、非临床医生」三重声明（对齐 FTC 执法与州披露法；MoodHub 不进入任何"care loop"表述）
- [ ] 危机转介协议可审计：本地规则引擎的危机识别命中事件可导出审计日志（对齐加州 SB 243 记录保留思路，但默认不采集、仅用户主动导出）
- [ ] 发布前测试记录：AI 回复模板与规则引擎变更前运行本地测试套件，留痕于仓库 docs/（对齐 VERA-MH 五系统分离的"发布前测试"与"人工升级"）
- [ ] 隐私政策机器可读化：以「无账号 / 无 SDK / 无遥测 / 数据不出本机」四段式呈现，一屏内读完
- [ ] 州法兼容矩阵文档：随 [RESEARCH-2026.md](RESEARCH-2026.md) 的监管快照同步维护，发布渠道按目标市场勾选合规项

## 竞品教训（2026-09 新增）

- **Woebot 的转身**：拥有强 RCT 证据仍因 FDA 合规成本关停消费者端（2025-06-30）。教训：面向消费者的"治疗"主张成本极高，MoodHub 坚持 wellness 定位、不做治疗性宣称。
- **Slingshot Ash 的对照**：9,300 万美元资本押注"首个为治疗设计的 AI"，与 Woebot 一热一冷，说明资本热度与临床验证的张力仍无解。MoodHub 无需参与这场赌博。
- **Character.AI / Google 和解**（2026-01）：开放端生成式陪伴产品在危机场景的追责风险已落地为真实诉讼。MoodHub 的危机识别不走 AI、不发网络请求，是结构性避险。
- **企业市场的门**：雇主付费模式（Lyra / Spring / Headspace）与 FHIR / 结局指标采购标准，对个人工具不适用；MoodHub 守住个人本地场景即可，不追企业采购。
