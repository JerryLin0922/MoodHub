# MoodHub 产品路线图 2026

> 更新日期：2026-09-28（第二轮：监管对齐细化）
> 基于第一性原理：MoodHub 的本质价值 = **私密的自我记录 + 即时的情绪陪伴 + 可回溯的数据洞察**。所有功能决策以不破坏「本地优先」为底线。
> 本版纳入 2026-09 用户反馈（日记趣味性、导入引导、陪伴定位），详见 [FEEDBACK-2026.md](FEEDBACK-2026.md)。

## 第一性原理审视

- 用户真正需要什么？被听见（树洞）、被理解（AI 回复）、看见自己的变化（总览 / 量表）。
- 行业证明什么？「不需要被教育，只需要被听见」；隐私是 2026 年最强差异化；监管正把「无治疗主张 + 本地处理」变成最低摩擦路径；Woebot 关停证明证据型产品靠消费者订阅难以为继，B2B2C 与 AI + 真人分层更稳。
- 我们坚决不做什么？不做云端账号、不做广告 SDK、不做情感成瘾设计、不把用户数据用于任何训练、不做任何治疗性宣称、不做付费陪聊式的情感依赖生意。

## 阶段一：隐私地基加固（当前 ~ v0.2）

- [x] 危机资源全球化：内置中国大陆（12356）、香港（18111 / Open噏）、美国 / 加拿大（988）等多地区资源卡
- [ ] 数据导出：一键导出全部日记 / 树洞 / 量表记录（JSON + CSV）
- [ ] 数据清除：一键清空全部本地数据（含 AI Key 持久化项）
- [ ] 离线可用性验证：飞行模式下全功能回归测试
- [ ] 导入引导（新，来自用户反馈）：三步向导（选择来源 → 选择文件或粘贴 → 预览确认）；来源模板（Apple 健康 / Google Fit / 华为运动健康 / Daylio 导出 CSV、通用 JSON）；内置示例数据；空状态说明卡

## 阶段二：洞察闭环与体验升级（v0.3）

- [ ] 情绪可视化：树洞 / 日记自动提取情绪关键词，生成「情绪足迹」时间线（借鉴能量卡片思路，纯本地规则引擎）
- [ ] 周期性回顾报告：周报 / 月报（睡眠、心情、量表趋势）
- [ ] 情绪模式提示：如「最近 7 天焦虑评分上升」的本地规则提示 + 建议资源卡
- [ ] 游戏化日记（新，来自用户反馈）：情绪花园（每次记录生成一朵情绪花，连续记录解锁装饰）；快捷情绪按钮（3 秒内完成，文字备注可选）；streak + 成就勋章；主题化日记页与微动画。实证依据：2025 ICITRI 研究（32 名 18-25 岁受试者，一个月，DASS-42 显著下降，p < 0.05）

## 阶段三：AI 深化与合规（v0.4+）

- [x] 本地 LLM 接入（Ollama / LM Studio 协议）：真正全离线的 AI 回复（新增内置预设，本地端点无需 API Key）
- [x] 未成年人模式：响应《人工智能拟人化互动服务管理暂行办法》与未成年人网络保护指南、加州 SB 243、EU AI Act 年龄保证要求，为 <18 用户提供纯本地记录模式，与陪伴式 AI 交互隔离；不提供虚拟亲密关系类交互；年龄判定采用出生年份输入 + 确认（超越自选复选框）
- [x] AI 身份标识：所有 AI 回复明确标注「AI 生成」并周期性提醒（每日首次进入树洞提示，对齐加州 SB 243 / EU AI Act /《办法》思路）
- [x] 防依赖设计：AI 回复不做过度迎合、不诱导持续停留（system prompt 边界规则），连续使用超 2 小时弹窗休息提醒（对齐中国《办法》）
- [x] 可选 E2EE 备份（实验性）：passphrase → PBKDF2-SHA256(310k) → AES-256-GCM，加密包仅含 salt/iv/密文，可放心存放；恢复走全量覆盖（基础版）
- [x] AI + 真人混合陪伴探索（基础版）：本地 AI 承担 24/7 即时倾听与记录，真人（志愿者 / 专业人士）作为可选匿名升级路径——树洞常驻「真人支持渠道」入口，用户主动寻求真人/人工支持时回复附带渠道卡；危机场景仍优先升级人工；不做付费墙式情感依赖生意（参照 Wysa 的 B2B2C 与 Talkspace Tee 的分层定价思路，但以本地优先为底线）

## 阶段四：合规与信任增强（v0.5+，2026-09 新增）

- [ ] 合规文案基线：商店页 / 应用内免责声明明确「非治疗、非危机服务、非临床医生」三重声明（对齐 FTC 执法与州披露法；MoodHub 不进入任何"care loop"表述）
- [ ] 危机转介协议可审计：本地规则引擎的危机识别命中事件可导出审计日志（对齐加州 SB 243 记录保留思路，但默认不采集、仅用户主动导出）
- [ ] 发布前测试记录：AI 回复模板与规则引擎变更前运行本地测试套件，留痕于仓库 docs/（对齐 VERA-MH 五系统分离的"发布前测试"与"人工升级"）
- [ ] 隐私政策机器可读化：以「无账号 / 无 SDK / 无遥测 / 数据不出本机」四段式呈现，一屏内读完
- [ ] 州法兼容矩阵文档：随 [RESEARCH-2026.md](RESEARCH-2026.md) 的监管快照同步维护，发布渠道按目标市场勾选合规项

## 竞品教训（2026-09 新增）

- **Woebot 的转身**：拥有强 RCT 证据仍因 FDA 合规成本关停消费者端（2025-06-30）。教训：面向消费者的"治疗"主张成本极高，MoodHub 坚持 wellness 定位、不做治疗性宣称。
- **Slingshot Ash 的对照**：9,300 万美元资本押注"首个为治疗设计的 AI"，与 Woebot 一热一冷，说明资本热度与临床验证的张力仍无解。MoodHub 无需参与这场赌博。
- **Character.AI / Google 和解**（2026-01）：开放端生成式陪伴产品在危机场景的追责风险已落地为真实诉讼。MoodHub 的危机识别不走 AI、不发网络请求，是结构性避险。
- **企业市场的门**：雇主付费模式（Lyra / Spring / Headspace）与 FHIR / 结局指标采购标准，对个人工具不适用；MoodHub 守住个人本地场景即可，不追企业采购。
