# MoodHub 产品路线图 2026

> 更新日期：2026-09-28
> 基于第一性原理：MoodHub 的本质价值 = **私密的自我记录 + 即时的情绪陪伴 + 可回溯的数据洞察**。所有功能决策以不破坏「本地优先」为底线。
> 本版纳入 2026-09 用户反馈（日记趣味性、导入引导、陪伴定位），详见 [FEEDBACK-2026.md](FEEDBACK-2026.md)。

## 第一性原理审视

- 用户真正需要什么？被听见（树洞）、被理解（AI 回复）、看见自己的变化（总览 / 量表）。
- 行业证明什么？「不需要被教育，只需要被听见」；隐私是 2026 年最强差异化；Woebot 关停证明证据型产品靠消费者订阅难以为继，B2B2C 与 AI + 真人分层更稳。
- 我们坚决不做什么？不做云端账号、不做广告 SDK、不做情感成瘾设计、不把用户数据用于任何训练、不做付费陪聊式的情感依赖生意。

## 阶段一：隐私地基加固（当前 ~ v0.2）

- [x] 危机资源全球化：内置中国大陆（12356）、香港（18111 / Open噏）、美国 / 加拿大（988）等多地区资源卡
- [ ] 数据导出：一键导出全部日记 / 树洞 / 量表记录（JSON + CSV）
- [ ] 数据清除：一键清空全部本地数据（含 AI Key 持久化项）
- [ ] 离线可用性验证：飞行模式下全功能回归测试
- [ ] 导入引导（新，来自用户反馈）：三步向导（选择来源 → 选择文件或粘贴 → 预览确认）；来源模板（Apple 健康 / Google Fit / 华为运动健康 / Daylio 导出 CSV、通用 JSON）；内置示例数据；空状态说明卡

## 阶段二：洞察闭环与体验升级（v0.3）

- [ ] 情绪可视化：树洞 / 日记自动提取情绪关键词，生成「情绪足迹」时间线（借鉴能量卡片思路，纯本地规则引擎）
- [ ] 周期性回顾报告：周报 / 月报（睡眠、心情、量表趋势）
- [ ] 情绪模式提示：如「最近 7 天焦虑评分上升」的本地规则提示 + 建议资源卡
- [ ] 游戏化日记（新，来自用户反馈）：情绪花园（每次记录生成一朵情绪花，连续记录解锁装饰）；快捷情绪按钮（3 秒内完成，文字备注可选）；streak + 成就勋章；主题化日记页与微动画。实证依据：2025 ICITRI 研究（32 名 18-25 岁受试者，一个月，DASS-42 显著下降，p < 0.05）

## 阶段三：AI 深化与合规（v0.4+）

- [ ] 本地 LLM 接入（Ollama / LM Studio 协议）：真正全离线的 AI 回复
- [ ] 未成年人模式：响应《人工智能拟人化互动服务管理暂行办法》与未成年人网络保护指南，为 <18 用户提供纯本地记录模式，与陪伴式 AI 交互隔离；不提供虚拟亲密关系类交互
- [ ] AI 身份标识：所有 AI 回复明确标注「AI 生成」并周期性提醒（对齐加州 SB 243 / EU AI Act /《办法》思路）
- [ ] 防依赖设计：AI 回复不做过度迎合、不诱导持续停留，设置会话边界与休息提示
- [ ] 可选 E2EE 备份（实验性）
- [ ] AI + 真人混合陪伴探索（新，来自定位讨论）：本地 AI 承担 24/7 即时倾听与记录，真人（志愿者 / 专业人士）作为可选匿名升级路径；定位为支持工具，危机场景升级人工；不做付费墙式情感依赖生意（参照 Wysa 的 B2B2C 与 Talkspace Tee 的分层定价思路，但以本地优先为底线）

## 竞品参考

- found.fun：情绪可视化闭环（能量卡片 + 能量足迹）
- Clarity：CBT 思想记录，本地默认存储
- EmoSApp：1B 级设备端心理支持模型
- Wellness AI：对话后生成个性化冥想
- Finch / Heart Garden / Voidpet Garden：游戏化日记（宠物养成、情绪花园、情绪生物）
- Daylio：图标速记 + 挑战勋章 + CSV 导出
- Wysa / Talkspace Tee：AI 陪伴商业化（B2B2C、分层定价、临床监督）
- Woebot：消费者订阅模式的教训样本
- 给力心理 / 旧纸树洞：付费倾诉市场参照（价格带、隐私卖点）
