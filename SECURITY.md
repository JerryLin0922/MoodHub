# Security Policy

## Supported Versions

MoodHub is an open-source, local-first project. Only the latest release
receives security updates. Older releases are not patched retroactively.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

We take security seriously. MoodHub is designed to keep all personal health
data on the user's own device — no accounts, no telemetry, no third-party
tracking SDKs. If you discover a vulnerability, please report it privately
so it can be fixed before public disclosure.

**How to report:**

- Open a private security advisory on GitHub:
  https://github.com/JerryLin0922/MoodHub/security/advisories/new
- Or email the maintainer via the address listed on the GitHub profile.

**What to expect:**

- We will acknowledge the report within 5 business days.
- We will keep you updated on the fix timeline.
- If the issue is accepted, a patched release will be published and the
  advisory will be credited to you (unless you prefer to stay anonymous).
- If the issue is declined, we will explain why.

Please do **not** open a public issue for security problems.
